# Convert Frontend to Use External API

## Summary
Update the frontend JavaScript files to point to `https://api-ifmc.onrender.com/` instead of using the relative `/api` path.

## Files to Modify

1. **src/js/admin.js** (line 21)
   - Change `const API_URL = '/api';` to `const API_URL = 'https://api-ifmc.onrender.com/api';`

2. **src/js/booking.js** (line 2)
   - Change `const API_URL = '/api';` to `const API_URL = 'https://api-ifmc.onrender.com/api';`

3. **src/js/status.js** (line 2)
   - Change `const API_URL = '/api';` to `const API_URL = 'https://api-ifmc.onrender.com/api';`
